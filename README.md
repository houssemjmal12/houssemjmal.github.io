## About

I am an AI Research Scientist and Engineer, currently a PhD candidate at Nantes Université / Inria (LS2N laboratory, STACK team), with a defense planned for January 2027. My published research covers **federated learning** and **network security**, and I have hands-on experience in end-to-end ML development and cloud deployment.

My work spans federated intrusion detection on non-IID data, client selection with offline reinforcement learning, free-rider detection, and multimodal phishing detection with vision-language models. I also run [Mycelia & Rays](https://myceliandrays.com/), a part-time project that applies LLMs and hybrid search to medical document libraries.

## Research

| Topic | What I did |
|---|---|
| **Federated intrusion detection** | Developed distributed deep learning optimization algorithms for intrusion detection on non-IID network traffic, improving convergence rate and detection accuracy, with theoretical convergence guarantees. |
| **Client selection with offline RL** | Designed a Decision Transformer-based client selection framework that reduces computation and communication time; extended it with an MLOps lifecycle driven by a trajectory-diversity trigger for data shift. |
| **Free-rider detection** | Developed a gradient-sensitivity-based out-of-distribution (OOD) detection method, and statistical tests applied during critical learning periods that measure dependence, innovation and effort of client updates. |
| **Multimodal phishing detection** | Built a framework combining URL features, HTML DOM parsing and webpage screenshots analyzed with VLMs (Qwen2-VL, SmolVLM-Instruct, Llama-3.2-11B-Vision-Instruct), fine-tuned with PEFT under federated learning. |
